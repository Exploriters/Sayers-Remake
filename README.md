## 概述
这是一款以**赛尔斯种族**为核心的种族MOD，以Humanoid Alien Races Framework为前置。<br>
赛尔斯是一种奇怪的、强力但是不稳定的人造生物，是植物与哺乳动物的粗暴融合体。它们被它们的创造者无情抛弃，而现在它们将踏上那不可能的归家之旅。<br>

## Q&A
**Q:这个MOD的强度怎么样？**<br>
A:说句实在话，我不是很清楚。如果从数值上来说，那这极有可能是个正义模组，因为猫花有很高的数值和很低的需求，加上高群居性，你很容易就能得到很多……几乎等同于满配小人的猫猫们。我在意识到这个问题后已经有些迟了，“高数值”已经几乎变成了这个种族的核心标签，我已经不太好改了。因此，我决定从机制上削弱它们。<br>
**Q:我感觉这个模组太正义了……**<br>
A:尽情期待。<br>
**Q:支持CombatExtended(CE)吗？**<br>
A:我不主玩CE，但是我会确保最低限度的支持……但是效果不保证。<br>
**Q:兼容xxx(任意模组)吗？**<br>
A:我玩的模组不多，但是如果有想要联动或者兼容的，可以提出来！如果有能力，我会去做的。<br>
**Q:我不喜欢里面的一些内容！**<br>
A:嗯，塞尔斯当中有一部分内容是我因为糟糕的精神状态写出来的，它确实可能引起不适，我在此致歉。对于这部分敏感内容，我会提供设置来让大家可以关闭其中一部分。<br>
**Q:什么时候会更新/完善？**<br>
A:有生之年，会更，但我不敢保证什么时候更。原因还是那几件：学业、疾病。<br>
**Q:爱猫TV？**<br>
A:这是环世界的一环，我不予以阻止。但是作为一个对自己的种族倾注了不知道多少心血的作者，我衷心希望这种东西玩可以，发布也可以，但是请不要将其直接送到我面前来。嗯，也就是不故意跳脸就没问题。
